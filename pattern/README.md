
# ✨ Java Pattern Programs

This repository contains `patterns.java`, a collection of **Java programs to print different types of patterns**.  
It is designed for beginners and students to practice **loops, conditionals, and nested structures**.

---

## 📂 Contents
The file demonstrates multiple categories of patterns:

### 1. ⭐ Star Patterns
- Right‑angled triangle
- Inverted triangle
- Pyramid
- Diamond
- Hollow square/rectangle

### 2. 🔢 Number Patterns
- Incremental sequences (e.g., `1234`)
- Continuous numbers across rows
- Inverted number triangles
- Pascal‑style arrangements

### 3. 🔤 Character Patterns
- Alphabet sequences (`A`, `AB`, `ABC`)
- Pyramid of letters
- Repeated character blocks

### 4. 🎨 Advanced Patterns
- Butterfly pattern
- Hollow pyramid
- Diamond with stars and numbers
- Mixed star/number/character designs

---

## 🛠 How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/abinash7854053195-design/Abi_Java.git
   ```
2. Navigate to the project folder:
   ```bash
   cd Abi_Java
   ```
3. Compile and run:
   ```bash
   javac patterns.java
   java patterns
   ```
