
# Basic Calculator 🧮

A simple Java-based calculator application that performs basic arithmetic operations.  
This project is designed to demonstrate fundamental Java concepts such as classes, methods, and user input handling.

---

## ✨ Features
- Addition ➕
- Subtraction ➖
- Multiplication ✖️
- Division ➗
- Handles invalid inputs gracefully

---

## 📂 Project Structure
```
Basic_Calculator/
│
├── calculator.java   # Main source file containing calculator logic
```

---

## 🚀 Getting Started

### Prerequisites
- Java Development Kit (JDK) 8 or higher
- A code editor or IDE (e.g., IntelliJ IDEA, Eclipse, VS Code)

### Compilation
Open a terminal in the project directory and run:
```bash
javac calculator.java
```

### Execution
After compilation, run the program with:
```bash
java calculator
```

---

## 🛠️ Example Usage
```
Enter first number: 10
Enter operator (+, -, *, /): *
Enter second number: 5
Result: 50
```
