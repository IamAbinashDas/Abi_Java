
# Abi_Java ☕

A structured repository containing Java implementations of essential Data Structures, Algorithms, problem-solving techniques, and practical mini-projects.

---

## 📂 Repository Structure

The code is organized into topic-specific directories:

| Folder | Description |
| :--- | :--- |
| `2D-Arrays/` | Matrix manipulations, search algorithms, and 2D grid problems |
| `Backtracking/` | N-Queens, Sudoku solver, subset generation, and permutations |
| `Basic_Calculator/` | Arithmetic expression parsing and implementation |
| `Recursion/` | Fundamental and advanced recursive problem sets |
| `Shortest_Path Problem/` | Graph traversals and pathfinding algorithms (Dijkstra, BFS, etc.) |
| `Sorting Methods/` | Bubble, Selection, Insertion, Merge, and Quick Sort algorithms |
| `Stock_Problem/` | Best Time to Buy and Sell Stock variations (Dynamic Programming/Greedy) |
| `Trapping Rain Water/` | Two-pointer and prefix/suffix array solutions |
| `pattern/` | Console-based nested loop logic and geometric patterns |

---

## 🛠️ Prerequisites

* **Java Development Kit (JDK):** Version 8 or higher (JDK 17+ recommended)
* **IDE / Editor:** Any text editor or IDE (VS Code, IntelliJ IDEA, Eclipse)

Check your Java installation:
```bash
java -version
javac -version

```

---

## 🚀 How to Run

1. **Clone the repository:**
```bash
git clone [https://github.com/IamAbinashDas/Abi_Java.git](https://github.com/IamAbinashDas/Abi_Java.git)
cd Abi_Java

```


2. **Navigate to the desired folder:**
```bash
cd "Sorting Methods"

```


3. **Compile the Java file:**
```bash
javac FileName.java

```


4. **Execute the compiled program:**
```bash
java FileName

```
