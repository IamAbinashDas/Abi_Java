
# 🔄 Basics of Recursion in Java

This repository contains `recursion.java`, a collection of **Java programs demonstrating recursion**.  
It is designed for beginners to understand how functions can call themselves to solve problems.

---

## 📚 What is Recursion?
Recursion is a programming technique where a function calls itself to break down a problem into smaller subproblems.  
Every recursive function has two essential parts:
1. **Base Case** – The condition that stops recursion.
2. **Recursive Case** – The part where the function calls itself.

---

## 📂 Contents
The file demonstrates several fundamental recursion examples:

### 1. Factorial of a Number
- Example: `factorial(5) = 5 * 4 * 3 * 2 * 1`

### 2. Fibonacci Sequence
- Example: `fibonacci(6) = 0, 1, 1, 2, 3, 5`

### 3. Sum of Natural Numbers
- Example: `sum(5) = 1 + 2 + 3 + 4 + 5`

### 4. Printing Numbers
- Print numbers in ascending and descending order using recursion.

### 5. Advanced Examples
- Recursion in arrays (searching, summing elements).
- Recursion in strings (reverse, palindrome check).
