
# Backtracking in Java

This folder contains Java implementations of classic **Backtracking algorithms**.  
Backtracking is a problem-solving technique that incrementally builds solutions and abandons them if they fail to satisfy constraints (also known as "backtracking" or "backtracking search").

## 📂 Contents
- **Basic.java** → Demonstrates the core idea of backtracking with simple examples.
- **Subset.java** → Generates all possible subsets of a given set.
- **Grid.java** → Explores paths in a grid using backtracking.
- **NQueens.java** → Solves the famous N-Queens problem.
- **Permutations.java** → Generates all permutations of a given array/string.
- **Sudoku.java** → Solves Sudoku puzzles using backtracking.

## 🚀 How to Run

   ```bash
   git clone https://github.com/IamAbinashDas/Abi_Java.git
   ```
2. Navigate to the `Backtracking` folder:
   ```bash
   cd Abi_Java/Backtracking
   ```
3. Compile and run any file using:
   ```bash
   javac FileName.java
   java FileName
   ```

## 🎯 Key Concepts
- **Recursive exploration**: Try possible options step by step.
- **Constraint checking**: Abandon paths that violate rules.
- **Solution building**: Collect valid solutions once constraints are satisfied.
